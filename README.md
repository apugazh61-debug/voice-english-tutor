# 🌸 Waheeda - Voice English Tutor AI

Waheeda is an interactive AI English Tutor designed to help Tamil speakers master spoken and written English.

## ✨ Features
- 🎙️ **Real-time Voice Conversation & Calling**: Talk naturally with Waheeda using voice input.
- 💬 **Bilingual Support**: Speak in Tamil, Thanglish, or English — Waheeda responds in clear, simple English.
- 🖼️ **Multimodal Analysis**: Upload Images, Audio, or Videos for AI analysis and explanation.
- 🔊 **Natural Voice Response**: Powered by Edge-TTS for realistic voice output.
- ⚡ **Powered by Groq**: High-speed Llama 3.3 70B, Whisper Large v3 STT, and Qwen Vision.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/your-username/voice-english-tutor.git
cd voice-english-tutor
```

### 2. Set up Environment Variables
Create a `.env` file in the root directory:
```env
GROQ_API_KEY=your_groq_api_key_here
```

### 3. Install Backend Dependencies & Run Server
```bash
pip install -r requirements.txt
python main.py
```

### 4. Build Frontend (Optional for dev)
```bash
cd frontend
npm install
npm run build
```

Open `http://localhost:8000` in your browser! 🎧
